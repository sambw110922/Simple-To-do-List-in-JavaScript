# Simple-To-do-List-in-JavaScript
This project is the front-end for a simple to-do list using HTML, JavaScript and CSS.

Included

1. simpletodolist.html – the HTML page for the project.
2. simpletodolistlogic.js – the JavaScript for the project.
3. simpletodolist_mobileTest.html – a HTML that contains all code for a mobile test.
4. simpletodostyle.css – the CSS for the project.

Instructions

1. Download
2. Open simpletodolist.html or simpletodolist_mobileTest.html in a browser.
3. Enter a task and assign a priority.
4. Press the “+” button.
5. Complete, delete, edit or filter tasks as necessary.

Notes

1. This is simply a front-end project. Tasks are not saved, they get reset when on close or page refresh.
2. A default task "hello world" is always created as an example of how tasks look.
